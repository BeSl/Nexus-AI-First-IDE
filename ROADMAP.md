🗺️ Nexus Agent IDE: Roadmap & Implementation PlanЭтот документ описывает поэтапный процесс создания кроссплатформенной IDE на базе Code-OSS, оптимизированной для разработки исключительно через ИИ-агентов с использованием фреймворка AgentTS.🏗 Фаза 1: Инфраструктура и "Зрение" (MVP)Цель: Подготовить среду Code-OSS и научить ИИ понимать структуру проекта без перерасхода токенов.[ ] 1.1. Setup Code-OSS EnvironmentФоркнуть репозиторий VS Code (Code-OSS).Очистить от телеметрии Microsoft.Настроить сборку под основные платформы (Web, Desktop).[ ] 1.2. Context Engine (Core)Реализовать парсер на базе TypeScript Compiler API.Создать генератор Project Skeleton (извлечение сигнатур без тел функций).Интеграция локального векторного индекса для семантического поиска по коду.[ ] 1.3. LLM GatewayНастроить шину обмена данными с Claude 3.5 Sonnet / Gemini 1.5 Pro.Реализовать поддержку MCP (Model Context Protocol).🤖 Фаза 2: Оркестрация и Инструментарий (Alpha)Цель: Создать систему команд, с помощью которых ИИ будет изменять код и проверять себя.[ ] 2.1. Agent OrchestratorРеализовать машину состояний на XState для контроля логики агента.Разделить роли: Architect (планирование), Coder (написание), Reviewer (контроль).[ ] 2.2. Virtual File System (VFS)Создать слой изоляции, где агент хранит черновики правок до одобрения пользователем.[ ] 2.3. Shadow Build SystemРеализовать фоновую сборку в директории .nexus/shadow.Автоматический перехват ошибок компиляции и передача их агенту на самоисправление.🛡 Фаза 3: AgentTS и Enterprise-контроль (Beta)Цель: Внедрить строгие правила разработки, которые сделают код поддерживаемым и безопасным.[ ] 3.1. AgentTS FrameworkРазработать набор ESLint/Biome правил, блокирующих "плохой" код от ИИ.Реализовать Contract-First Engine: запрет на генерацию логики без предварительных интерфейсов.[ ] 3.2. Human-in-the-Loop DashboardСоздать UI-панель "Review & Diff", где оператор одобряет изменения поблочно.Визуализация графа зависимостей: показ того, что сломается при изменении.[ ] 3.3. TDD AutomationИнтегрировать агента-тестировщика, который пишет тесты на Vitest/Playwright параллельно с кодом.🚀 Фаза 4: Масштабирование и РелизЦель: Оптимизация под высокие нагрузки и кроссплатформенную разработку.[ ] 4.1. Cross-Platform SDKsПодготовить шаблоны (Blueprints) для React Native, Electron и Backend (Node/Bun).[ ] 4.2. Security LayerВнедрить автоматический аудит безопасности (SAST) для каждой итерации кода.[ ] 4.3.

# Идея и цель

## Проблема

Современные IDE ориентированы на инструменты, а не на процесс разработки.  
AI-плагины помогают, но **не меняют парадигму**.

## Решение

Nexus-AI-First-IDE создаёт **AI-native runtime**:

- Многоагентная оркестрация: Architect, Coder, Reviewer, Tester
- Структурированные действия (DevActions)
- Детерминированное воспроизведение шагов
- Возможность подключать разные среды (VS Code, CLI, CI)

![Architecture](public/architecture.svg)

## Цель

Создать прототип runtime следующего поколения, который:

- позволяет LLM работать безопасно и reproducibly  
- обеспечивает прозрачность и объяснимость  
- является исследовательской платформой для AI-first разработки

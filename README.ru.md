# Nexus Agent IDE

> AI-агент для разработки TypeScript-приложений, встроенный в VS Code.

---

## Что это такое

**Nexus Agent IDE** — расширение для VS Code, которое автоматически проектирует, пишет, проверяет и тестирует ваш TypeScript-код с помощью цикла из четырёх AI-агентов. Вам нужно только описать задачу на русском или английском — Nexus сделает всё остальное.

Ключевой принцип: **человек как архитектор, AI как исполнитель**. Вы всегда видите и подтверждаете каждый сгенерированный файл перед тем, как он попадёт на диск.

---

## Как работает: Nexus Loop

```
Вы описываете задачу
         ↓
  ┌──────────────┐
  │  Architect   │ — проектирует архитектуру, создаёт интерфейсы TypeScript
  └──────┬───────┘
         │ ← вы подтверждаете план
  ┌──────▼───────┐
  │    Coder     │ — реализует код во временной файловой системе (VFS)
  └──────┬───────┘
  ┌──────▼───────┐
  │   Reviewer   │ — проверяет код: типобезопасность, безопасность, стиль
  └──────┬───────┘
  ┌──────▼───────┐
  │    Tester    │ — генерирует тесты Vitest для каждого модуля
  └──────┬───────┘
         │ ← вы подтверждаете файлы
  Файлы записываются в ваш проект
```

Весь цикл визуализируется в реальном времени через граф React Flow в отдельной панели.

## Установка расширения

### Вариант 1: через .vsix (рекомендуется)

1. Скачайте файл `nexus-agent-ide-*.vsix` из раздела [Releases](https://github.com/nexus-ai/nexus-agent-ide/releases)
2. В VS Code откройте `Ctrl+Shift+P` → **Extensions: Install from VSIX...**
3. Выберите скачанный файл
4. Нажмите **Reload Window**

### Вариант 2: из исходного кода

```bash
git clone https://github.com/nexus-ai/nexus-agent-ide.git
cd nexus-agent-ide
npm install
npm run compile
npm run build
```

Нажмите **F5** в VS Code — откроется окно Extension Development Host.

## Настройка провайдера

Откройте **Мастер настройки** через `Ctrl+Shift+P` → **Nexus: Мастер настройки** (или автоматически при первом запуске).

### Anthropic Claude (рекомендуется)

Лучшее качество кода. Требует платного API-ключа.

1. Зарегистрируйтесь на [console.anthropic.com](https://console.anthropic.com)
2. Создайте API-ключ (начинается с `sk-ant-...`)
3. В VS Code: `Ctrl+,` → поиск `nexus.llm` → введите ключ в поле **Anthropic API Key**

> Или в терминале перед запуском VS Code: `export ANTHROPIC_API_KEY=sk-ant-...`

### Google Gemini

Быстрый, есть бесплатный уровень доступа.

1. Получите ключ на [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
2. В настройках Nexus: выберите провайдер **gemini**, введите ключ в поле **Gemini API Key**

### Ollama (локально, без интернета)

Полностью офлайн. Данные не покидают ваш компьютер.

1. Установите [Ollama](https://ollama.ai/download)
2. Запустите сервер: `ollama serve`
3. Загрузите модель: `ollama pull codellama` (или `llama3`, `mistral`)
4. В настройках Nexus: выберите провайдер **ollama**

## Первый запуск: шаг за шагом

### Способ A: через Мастер настройки

1. При первом запуске расширения автоматически откроется **Мастер настройки**
2. **Шаг 1** — Ознакомьтесь с описанием Nexus, нажмите «Начать настройку»
3. **Шаг 2** — Выберите AI-провайдера (кликните на карточку)
4. **Шаг 3** — Введите API-ключ или URL Ollama
5. **Шаг 4** — Опишите первую задачу, нажмите «🚀 Запустить Nexus»

### Способ B: напрямую

1. Откройте боковую панель Nexus (иконка 🤖 в левой панели активности)
2. Убедитесь, что в разделе **Configuration** нет красных иконок ошибок
3. Нажмите `Ctrl+Shift+P` → **Nexus: Run Agent Loop**
4. Введите описание задачи, нажмите Enter

## Боковая панель

В боковой панели Nexus два раздела:

### Configuration (Конфигурация)

| Индикатор | Значение |
|-----------|----------|
| ✅ `Provider: Anthropic (Claude)` | Провайдер выбран |
| ✅ `Anthropic API Key: ●●●● configured` | Ключ настроен |
| ❌ `Anthropic API Key: ⚠ not set — click to fix` | Ключ не настроен (кликните для исправления) |
| `Model: claude-sonnet-4-6 (default)` | Используемая модель |
| ▶ `Run Agent Loop…` | Запустить |
| ⚙ `Open Settings` | Настройки |

### Staged Files (Сгенерированные файлы)

Здесь появляются файлы, которые агенты создали, но ещё не записали на диск.
Вы видите каждый файл и можете его предварительно просмотреть.
Кнопки в заголовке раздела: **✓ Принять все** / **🗑 Отбросить всё**.

## Справка по настройкам

Все настройки доступны через `Ctrl+,` → поиск `nexus`.

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `nexus.llm.provider` | AI-провайдер: `anthropic`, `gemini`, `ollama` | `anthropic` |
| `nexus.llm.model` | Переопределение модели (оставьте пустым для дефолтной) | — |
| `nexus.llm.anthropic.apiKey` | API-ключ Anthropic (`sk-ant-...`) | — |
| `nexus.llm.gemini.apiKey` | API-ключ Google Gemini (`AIza...`) | — |
| `nexus.llm.ollama.baseUrl` | URL сервера Ollama | `http://localhost:11434` |

**Приоритет**: Настройки VS Code > переменные окружения > значение по умолчанию.

**Переменные окружения** (альтернатива настройкам):
```bash
ANTHROPIC_API_KEY=sk-ant-...
GEMINI_API_KEY=AIza...
OLLAMA_BASE_URL=http://localhost:11434
NEXUS_LLM_PROVIDER=anthropic
```

## Архитектура

```
VS Code Extension
├── Боковая панель
│   ├── Configuration (NexusStatusProvider) — статус конфигурации
│   └── Staged Files (NexusVfsProvider) — файлы до записи на диск
├── Панели (Webview)
│   ├── Architecture Graph (React Flow) — визуализация цикла агентов
│   ├── Approval Panel — подтверждение плана архитектора
│   └── Welcome Wizard — мастер первоначальной настройки
└── Логика
    ├── NexusLoop → XState-машина → 4 агента
    ├── AgentToolkit → Anthropic / Gemini / Ollama API
    ├── ContextEngine → TF-IDF индекс + TypeScript Compiler API
    └── WorkspaceCommitter → запись файлов на диск
```

## Часто задаваемые вопросы

**Q: Расширение показывает "Нет файлов" в боковой панели — это нормально?**
Да. Файлы появятся после того, как Nexus завершит цикл агентов.

**Q: Можно ли использовать без API-ключа?**
Да — с Ollama. Установите Ollama, загрузите модель `codellama` или `llama3`, выберите провайдер `ollama`.

**Q: Откуда берётся стоимость в уведомлении после выполнения?**
Nexus отслеживает использование токенов через TelemetryService и рассчитывает примерную стоимость по тарифам Anthropic/Gemini. Для Ollama стоимость всегда $0.

**Q: Как переключить провайдера?**
`Ctrl+Shift+P` → **Nexus: Open Settings** → измените `nexus.llm.provider`.

**Q: Можно ли использовать свою модель?**
Да. Задайте `nexus.llm.model` — например, `claude-opus-4-6`, `gemini-1.5-pro` или любую модель Ollama.

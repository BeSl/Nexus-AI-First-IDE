# Nexus IDE: Архитектурная топология

Система строится на базе Code-OSS и состоит из 4-х изолированных слоев:

1. **LSP Layer (Language Server):** Анализирует AST (дерево кода), извлекает типы и связи.
2. **Context Engine (The Brain):** Фильтрует код, создает "скелеты" файлов для LLM, управляет RAG (векторным поиском).
3. **Orchestrator:** Управляет жизненным циклом агентов (Architect -> Coder -> Tester).
4. **VFS (Virtual File System):** Песочница, где агенты вносят правки перед тем, как пользователь их подтвердит.

## Правило взаимодействия:
Агенты НЕ читают файлы напрямую. Они запрашивают данные через `ContextEngine.query()`.
